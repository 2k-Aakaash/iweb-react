# iWeb v2.1

The first automated release of the rebuilt iWeb.

## Highlights
- **Search:** a full search experience and a completely redesigned interface.
- **Unsplash wallpapers:** photo backgrounds from Unsplash.
- **Music Library:** AI-assisted library features and bug fixes.
- **Homepage and fonts:** a configurable homepage and custom font handling.
- **Settings:** export your data.

## Under the hood
- Every push to `main` is tested, built and published here as a release with `iWeb.Extension.zip` attached.
