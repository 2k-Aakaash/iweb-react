# iWeb v2.2

## New
- **Currency converter in the Smart Stack:**
  - flip from the weather card to a currency card by scrolling, swiping or using the arrow keys;
  - the card's colour follows the 7-day trend;
  - it expands into a converter with currency pickers, swap and a trend chart.
- **Currency in Spotlight:** type queries like `100 usd to inr`. Enter copies the result, and Ctrl/Cmd + Enter sends the pair to the widget.
- **In-extension updates:** Settings → About → Software Update downloads the latest release, checks its SHA-256 checksum, installs it and reloads iWeb.

## Improvements
- Rates are cached for offline use (ExchangeRate-API daily rates, Frankfurter history).
- Importing duplicate files is now deterministic: the first copy is always the one kept.
