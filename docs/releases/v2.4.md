# iWeb v2.4

## New
- **Photo credit:** "Photo by … on Unsplash" is shown on the new tab while an Unsplash photo is the wallpaper.
- **App-like dashboard:**
  - text can no longer be selected or dragged accidentally;
  - the pointer is an arrow everywhere except in text fields.

## Improvements
- On first launch, iWeb opens on a clean dark background instead of a fixed photo.
- Gallery thumbnails load straight from Unsplash, as its API guidelines require.
- Release versions now follow the changes they contain: new features bump the minor version, and fixes bump the patch.
