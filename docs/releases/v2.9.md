# iWeb v2.9

## Performance
- **Faster start-up:** the start-up bundle is 61% smaller (599 KiB → 232 KiB gzipped). Spotlight, Settings, backups and the Notes renderer load when first used.
- **Smoother glass:** far fewer repaints when hovering the Dock and opening Control Center.
- **Music:** the audio engine starts on first play instead of with every new tab.
- **Animations:** loading shimmers and headline animations run on the GPU.

## New
- **Login reveal:** each new tab opens from behind a dark, blurred veil that clears in about 0.3 seconds, like logging in on macOS 26.
- **New README:** describes iWeb, its features and how to install it.
