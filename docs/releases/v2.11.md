# iWeb v2.11: Notes and Daily Tasks

## New
- **Notes workspace:** three columns: views (All Notes, Pinned, Today, Upcoming, Overdue, All Tasks, Completed and tags), the notes in the selected view, and the editor.
- **Task Notes:**
  - Markdown checklists with a Checklist view;
  - tick, rename and reorder tasks;
  - due dates and priorities;
  - hide or clear completed tasks.
- **Sticky cards on the desktop:**
  - pin any task note to the desktop;
  - drag it anywhere;
  - it stays in sync with its note;
  - frosted glass by default, or a macOS Stickies colour.

## Improvements
- Notes opens instantly: it loads in the background while iWeb is idle.
- Long lists render progressively and scroll smoothly.
- Software Update shows the release date without the time.

Existing notes are preserved exactly as they were.
