# iWeb v2.10: Creator Widgets

## New
- **Creator Widgets:** a new category in the widget gallery.
- **YouTube Analytics:**
  - subscribers, total views and video count for any channel, by @handle, ID or link;
  - channel owners can connect with Google for 28-day views, watch time, subscriber changes, average view duration and, if allowed, estimated revenue;
  - small, medium and large sizes;
  - growth tracked over time on your device;
  - the last numbers stay visible if a refresh fails.

## Security
- Sign-in goes through iWeb's server, so secrets and tokens never reach the browser.
- Data refreshes only while the widget is on screen.

*Instagram Analytics is in development.*
