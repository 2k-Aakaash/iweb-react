# iWeb v3.3: Themes and the Theme Store

## New
- **Themes:** change iWeb's fonts, colours, window corners, glass, app icons, app names, wallpaper and interface sounds in one step. Find them in **Settings → Appearance → Theme**.
- **Theme Store:** browse themes, see their previews, install them and keep them up to date. Open it from Apps, or from **Settings → Appearance → Theme Store…**. While it's open it has its own Dock icon.
- **Install from File:** try a theme from a `.zip` before it's in the store.
- **Theme wallpapers:** when a theme comes with a wallpaper, iWeb offers to add it to your wallpapers. It stays there if you change theme later.
- **Theme sounds:** themes can bring short sounds for opening, closing and minimising windows and for notifications. Turn them off in **Settings → Appearance → Theme**.

## Safe by design
- **Themes are data only.** They can't run code or load anything from the internet.
- **Every theme is checked before it's installed:** its files, its styling and its size.
- **Store downloads are verified.** Each must match the checksum the store publishes, and be the theme and version the store lists.

## Improvements
- **A theme made for Dark or Light** keeps iWeb in that appearance while it's in use, and Settings says so.
- **Themes appear from the first frame.** The desktop is revealed with the theme already in place, its fonts loaded.
- **A theme missing after restoring a backup** shows a link to find it in the Theme Store.
- **Weather keeps itself up to date:** it refreshes every half hour and when you come back to the tab, and there's a Refresh button. It always shows the current hour.
- **Back to your current location:** after searching a city, the arrow button beside the search returns the Weather widget to where you are.
- **Weather at start:** the widget shows your last forecast straight away instead of "Loading".

## For theme makers
