# iWeb v2.5.1

## Fixes
- **Software Update:** Update Now is always available and asks for the extension folder when it needs it.
- **After an update:** iWeb reopens in the same tab instead of Chrome's default new tab page.
- **Unsplash offline:**
  - saved photos are shown after 8 seconds without a connection;
  - shuffle now rotates through every saved photo.
- Removed two console errors about the content security policy.
- Disabled buttons in Settings now look disabled.
